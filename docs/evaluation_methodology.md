# Evaluation methodology

Retrieval: Precision@K, Recall@K, Hit Rate@K, MRR, nDCG@K.

Generation/grounding: citation coverage, evidence-claim coverage, unsupported-claim rate, provenance validity, completeness rubric, safety flags, abstention, agreement/disagreement, and repeated-run consistency.

System: latency, provider calls, token usage when reported, failures, fallback use, and stage timing. Cost is omitted when unavailable.

Analysis reports count, mean, median, standard deviation, deterministic bootstrap confidence intervals, paired differences, and standardized effects where appropriate. It does not manufacture p-values or significance claims.
