# Supervisor research dashboard

The repository root is a static presentation layer served locally at `http://127.0.0.1:5500`. It combines:

- a local-only, sequential live demo that reuses `POST /api/research/run`;
- public-safe aggregate RQ1/RQ4 results generated by `build_research_results.py`;
- condition diagrams, charts, tables, workflow, and limitations.

## Local services

Port 5500 serves this supervisor dashboard. Port 5600 is a separate read-only RQ4 runner-state page and is not the main presentation frontend. The local demo backend can be started on any free port and exposed to the page through `window.MEDIRAG_API_BASE_URL`; the current supervisor setup uses port 8001 because port 8000 is occupied locally.

## Result provenance

Regenerate or verify the committed aggregate file with:

```powershell
.\.venv\Scripts\python.exe frontend\build_research_results.py
.\.venv\Scripts\python.exe frontend\build_research_results.py --check
```

`frontend/data/research_results.json` contains aggregate presentation metrics, source artifact paths, benchmark/corpus hashes, and source commits. It contains no raw corpus text, raw experiment outputs, or credentials. Frozen final artifacts remain authoritative.

## Public boundary

The static overview, formal aggregate results, charts, methodology, and limitations are presentation-safe. The 4,461-chunk local corpus, raw formal outputs, ignored research data, and `backend/.env` must never be deployed. The live experiment control disables itself outside localhost unless a secure server-side backend is deliberately configured; no provider credential belongs in HTML or JavaScript.
