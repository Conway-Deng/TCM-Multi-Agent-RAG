# TCM Gold Benchmark v1.2

Status: **FROZEN_SOURCE_GROUNDED_V1_2**

This directory contains the final pre-freeze source-grounded candidate. The formal benchmark contains 50 semantic-accuracy questions. - review_sheet_v1_2.csv — human-review worksheet
- coverage_report_v1_2.md — coverage and methodology summary

No C1/C2 run or provider/LLM call was performed during construction. The benchmark remains a draft until final human source review.
