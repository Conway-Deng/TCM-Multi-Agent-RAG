# Blinded semantic validation

This is a pending, 60-item human validation sample for the frozen semantic Gold protocol. Labels are intentionally blank and systems are shown only as SYSTEM_A/SYSTEM_B.

Launch from the repository root:

    .\.venv\Scripts\python.exe research\experiments\rq1_c1_vs_c2\formal_pass_1_retry_20260821\semantic_validation\reviewer\reviewer_server.py

Open http://127.0.0.1:8766. Save decisions to semantic_validation/human_validation.json. Stop the server with Ctrl+C.
